# JobPulse V1 - Project Overview

## Problem
Freshers spend significant time visiting multiple job portals every day, filtering duplicate jobs, checking whether openings are still active, and tracking applications manually.

## Solution
JobPulse is a personal job assistant that automatically fetches relevant jobs daily based on a user's resume and preferences, ranks them, and presents the top opportunities in one dashboard.

## Target User
- Single user (owner)
- Fresher / Early-career software engineer

## Goals
- Save time
- Never miss relevant openings
- Track applications
- Centralize job search

## Success Criteria
- Daily top 20 relevant jobs
- <10 minutes/day spent searching
